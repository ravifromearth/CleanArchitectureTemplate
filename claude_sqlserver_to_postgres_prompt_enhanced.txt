### Practice #5: Array Type Mappings (PostgreSQL Native Arrays)

**CRITICAL: PostgreSQL arrays must be explicitly configured**

**Entity Configuration for Arrays:**

```csharp
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

public static class EntityConfigurationExtensions
{
    public static void ConfigurePostgreSQLArrays<TEntity>(
        this EntityTypeBuilder<TEntity> entity) 
        where TEntity : class
    {
        // Configure array properties for PostgreSQL
        var arrayProperties = typeof(TEntity)
            .GetProperties()
            .Where(p => p.PropertyType.IsArray);
        
        foreach (var prop in arrayProperties)
        {
            if (prop.PropertyType == typeof(int[]))
            {
                entity.Property(prop.Name).HasColumnType("integer[]");
            }
            else if (prop.PropertyType == typeof(long[]))
            {
                entity.Property(prop.Name).HasColumnType("bigint[]");
            }
            else if (prop.PropertyType == typeof(string[]))
            {
                entity.Property(prop.Name).HasColumnType("text[]");
            }
            else if (prop.PropertyType == typeof(Guid[]))
            {
                entity.Property(prop.Name).HasColumnType("uuid[]");
            }
            else if (prop.PropertyType == typeof(decimal[]))
            {
                entity.Property(prop.Name).HasColumnType("numeric[]");
            }
            else if (prop.PropertyType == typeof(DateTime[]))
            {
                entity.Property(prop.Name).HasColumnType("timestamptz[]");
            }
            else if (prop.PropertyType == typeof(bool[]))
            {
                entity.Property(prop.Name).HasColumnType("boolean[]");
            }
        }
    }
}
```

## PostgreSQL SQL Syntax Patterns

### Standard PostgreSQL Syntax (use these patterns):

* **Pagination:** `LIMIT N OFFSET M`
* **Current Timestamp:** `now()` or `CURRENT_TIMESTAMP AT TIME ZONE 'UTC'`
* **Null Handling:** `COALESCE(a, b)` or `NULLIF(a, b)`
* **String Length:** `length(x)` or `char_length(x)`
* **Date Arithmetic:** 
  - `age(timestamp1, timestamp2)` for intervals
  - `timestamp + INTERVAL '1 day'` for date addition
  - `DATE_PART('year', timestamp)` for extracting parts
* **UUID Generation:** `gen_random_uuid()` (requires `pgcrypto` extension)
* **Upsert Pattern:** `INSERT ... ON CONFLICT (...) DO UPDATE SET ...`
* **Temporary Tables:** `CREATE TEMP TABLE temp_name (...)`
* **JSON Operations:** `jsonb_build_object()`, `jsonb_agg()`, `->`, `->>`
* **Function Calls:** `SELECT * FROM function_name(param1, param2)`
* **Procedure Calls:** `CALL procedure_name(param1, param2)`
* **Case Sensitivity:** Use lowercase for identifiers or quote them: `"TableName"`

### Data Type Mappings:

| .NET Type | PostgreSQL Type | Configuration |
|-----------|----------------|---------------|
| `Guid` | `uuid` | `.HasColumnType("uuid")` + `gen_random_uuid()` |
| `bool` | `boolean` | Native mapping |
| `DateTime` | `timestamptz` | `.HasColumnType("timestamptz")` |
| `string` (unlimited) | `text` | Native mapping |
| `string(n)` | `varchar(n)` | `.HasMaxLength(n)` |
| `byte[]` | `bytea` | Native mapping |
| `decimal(p,s)` | `numeric(p,s)` | `.HasPrecision(p,s)` |
| `int` | `integer` | Native mapping |
| `long` | `bigint` | Native mapping |
| `int[]` | `integer[]` | `.HasColumnType("integer[]")` |
| `string[]` | `text[]` | `.HasColumnType("text[]")` |
| `object` (JSON) | `jsonb` | `.HasColumnType("jsonb")` |

### LINQ / EF Core Patterns:

* **Case-Insensitive Search:**

## PostgreSQL Functions and Stored Procedures

### PL/pgSQL Function Template:

```sql
CREATE OR REPLACE FUNCTION function_name(
    param1_name param1_type,
    param2_name param2_type
)
RETURNS return_type
LANGUAGE plpgsql
AS $$
DECLARE
    var1 type;
    var2 type;
BEGIN
    -- Function logic
    SELECT column INTO var1
    FROM table_name
    WHERE condition;
    
    -- Conditional logic
    IF var1 IS NULL THEN
        RAISE EXCEPTION 'Error message';
    END IF;
    
    -- Return value
    RETURN var1;
    
EXCEPTION
    WHEN OTHERS THEN
        RAISE EXCEPTION 'Function failed: %', SQLERRM;
END;
$$;
```

### PL/pgSQL Procedure Template:

```sql
CREATE OR REPLACE PROCEDURE procedure_name(
    param1_name param1_type,
    param2_name param2_type,
    INOUT result_param result_type
)
LANGUAGE plpgsql
AS $$
DECLARE
    var1 type;
BEGIN
    -- Procedure logic
    var1 := param1_name + param2_name;
    
    -- Update INOUT parameter
    result_param := var1;
    
    COMMIT; -- Procedures can control transactions
    
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE EXCEPTION 'Procedure failed: %', SQLERRM;
END;
$$;
```

### View Template:

```sql
CREATE OR REPLACE VIEW view_name AS
SELECT 
    t1.column1,
    t2.column2,
    COUNT(*) as count_value
FROM table1 t1
INNER JOIN table2 t2 ON t1.id = t2.table1_id
GROUP BY t1.column1, t2.column2;
```

### Common PL/pgSQL Patterns:

* **Variable Declaration:** `DECLARE var_name type;`
* **Variable Assignment:** `var_name := value;`
* **Query Into Variable:** `SELECT column INTO var_name FROM table WHERE condition;`
* **Conditional:** `IF condition THEN ... ELSIF condition THEN ... ELSE ... END IF;`
* **Loop:** `FOR record IN SELECT ... LOOP ... END LOOP;`
* **Error Handling:** `RAISE EXCEPTION 'message: %', variable;`
* **Row Count:** `GET DIAGNOSTICS row_count = ROW_COUNT;`
* **Returning Clause:** `INSERT ... RETURNING id INTO var_id;`

### Bulk Insert Using PostgreSQL COPY:

```csharp
using Npgsql;

public async Task BulkInsertAsync<T>(IEnumerable<T> entities) where T : class
{
    var connection = (NpgsqlConnection)_context.Database.GetDbConnection();
    
    if (connection.State != System.Data.ConnectionState.Open)
        await connection.OpenAsync();
    
    using var writer = connection.BeginBinaryImport(
        "COPY users (id, name, email, created_at) FROM STDIN (FORMAT BINARY)");
    
    foreach (var entity in entities)
    {
        writer.StartRow();
        writer.Write(entity.Id, NpgsqlDbType.Uuid);
        writer.Write(entity.Name, NpgsqlDbType.Text);
        writer.Write(entity.Email, NpgsqlDbType.Text);
        writer.Write(entity.CreatedAt, NpgsqlDbType.TimestampTz);
    }
    
    await writer.CompleteAsync();
}
```

### Bulk Update Using Temporary Tables:

```csharp
public async Task BulkUpdateAsync(List<UpdateModel> updates)
{
    await using var transaction = await _context.Database.BeginTransactionAsync();
    
    try
    {
        // Create temp table
        await _context.Database.ExecuteSqlRawAsync(@"
            CREATE TEMP TABLE temp_updates (
                id uuid,
                new_value text
            ) ON COMMIT DROP;
        ");
        
        // Bulk insert into temp table
        var connection = (NpgsqlConnection)_context.Database.GetDbConnection();
        using var writer = connection.BeginBinaryImport(
            "COPY temp_updates (id, new_value) FROM STDIN (FORMAT BINARY)");
        
        foreach (var update in updates)
        {
            writer.StartRow();
            writer.Write(update.Id, NpgsqlDbType.Uuid);
            writer.Write(update.NewValue, NpgsqlDbType.Text);
        }
        
        await writer.CompleteAsync();
        
        // Perform update
        await _context.Database.ExecuteSqlRawAsync(@"
            UPDATE users u
            SET value = t.new_value
            FROM temp_updates t
            WHERE u.id = t.id;
        ");
        
        await transaction.CommitAsync();
    }
    catch
    {
        await transaction.RollbackAsync();
        throw;
    }
}
```

## Security & Best Practices

* **CRITICAL:** Use Npgsql 8.0.5 or later (8.0.0 has known high-severity vulnerability GHSA-x9vc-6hfv-hg8c)
* **Always** use parameterized queries - never concatenate SQL strings
* Enable SSL/TLS in connection strings for production: `SSL Mode=Require;Trust Server Certificate=false`
* Use connection pooling: `Maximum Pool Size=100;Minimum Pool Size=5`
* Set appropriate command timeouts: `Command Timeout=30`
* Store sensitive connection strings in user secrets or environment variables
* Use PostgreSQL roles and permissions for access control
* Enable audit logging in PostgreSQL for production environments
* Use `pg_stat_statements` extension for query performance monitoring
* Regularly run `VACUUM ANALYZE` for table maintenance
* Document PostgreSQL role/permission requirements in WARNINGS.md

## PostgreSQL Extensions to Consider

Document required extensions in **PG_EXTENSIONS.sql**:

```sql
-- Enable UUID generation
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- Enable full-text search (if needed)
CREATE EXTENSION IF NOT EXISTS "pg_trgm";
CREATE EXTENSION IF NOT EXISTS "unaccent";

-- Enable spatial data (if needed)
CREATE EXTENSION IF NOT EXISTS "postgis";

-- Enable JSON functions (usually built-in, but verify)
-- jsonb functions are built-in from PostgreSQL 9.4+

-- Enable statistics for performance monitoring
CREATE EXTENSION IF NOT EXISTS "pg_stat_statements";
```
